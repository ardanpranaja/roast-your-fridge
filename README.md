## The entry

> My fridge hums like a lawnmower, drips like a leaky gossip, and after twenty years on the job it still can't keep the milk cold — one job, and it quit.

## What main.ts does

`main.ts` holds the entry line as a constant, validates it against the gate (exactly one line, 1–200 characters, not only whitespace), then writes it to `entry.txt` inside the output directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`) and logs the character count. It has no dependencies — just Node.js 22 or later, which runs TypeScript directly.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the roast to `out/entry.txt`.
